- ## Task

Create a text-based clickbait headline generator that produces funny, exaggerated, and attention-grabbing headlines by combining random words with 
ready-made headline templates. The program should ask the user how many headlines they want, then display that many unique headlines on the screen. 
{/* This project is based on a Mad Libs-style approach, where the computer fills in blanks using random word lists to create many different headline combinations. */}

<CollapsibleSection title="Instructions">
- Ask the user how many clickbait headlines they want to generate.
- Use random words from different categories such as names, places, objects, timeline, adjectives etc.
- Combine those words with headline patterns to create exciting or silly headlines.
- Generate and display the requested number of headlines.
- Make sure each headline looks different and entertaining.
</CollapsibleSection>

<div class="w-full my-2"></div>

<CollapsibleSection title="Expected Output">
```ansi
### Clickbait Headline Generator ###

Our website needs to trick people into looking at ads!
Enter the number of clickbait headlines to generate: 5

What Boyfriends Don't Want You To Know About Girlfriends!
Big Companies Hate Him! See How This Georgia Teacher Invented a Cheaper Robot
Are Millenials Killing the Baba Industry?
16 Reasons Why Serial Killers Are More Interesting Than You Think (Number 4 Will Surprise You!)
You Won't Believe What This Gujarat Parent Found in Her Workplace!

Post these to our blog right now or you're fired!
```
